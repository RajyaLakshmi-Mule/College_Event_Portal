# PEC FEST 2026 – Responsive College Event Portal

## Project
This project is based on the assignment requirement for a Responsive College Event Portal.

### Included Features
- Responsive homepage
- Event listings
- Event registration form
- Event schedule
- Event gallery
- Contact section
- Mobile navigation menu
- JavaScript form validation
- Smooth scrolling
- Event buttons that automatically select the event in the registration form

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run in VS Code

1. Extract the ZIP file.
2. Open the `College_Event_Portal` folder in VS Code.
3. Open `index.html`.
4. Right-click `index.html` and select **Open with Live Server**.
5. If Live Server is not installed, install the VS Code extension named **Live Server**.
6. The website will open in your browser.
